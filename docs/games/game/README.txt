LAST TRAIN — 3D HORROR
=======================

START
1. ZIP entpacken.
2. index.html öffnen.
3. „STATION BETRETEN“ anklicken.

Das Spiel läuft offline in Firefox, Chrome, Edge und Safari.

PC
WASD          Bewegen
Maus          Umschauen
F             Taschenlampe
Shift         Rennen
P / Escape    Pause

HANDY / TABLET
Linker Joystick: bewegen
Rechte Bildschirmhälfte ziehen: umschauen
LICHT-Taste: Taschenlampe

ZIEL
Finde drei Sicherungen und erreiche das Notfalltor. Die Taschenlampe verbraucht
Akku und kann das Wesen auf deine Position aufmerksam machen.

Wenn es dich erwischt, rennt das Wesen auf die Kamera zu und springt dir als
echter 3D-Jumpscare direkt ins Gesicht.

Technik: HTML5, CSS3, JavaScript, WebGL und Three.js.
